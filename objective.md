# LocalScribe iOS objective

Build an open-source native iOS LocalScribe with local speech recognition and a polished dictation app and keyboard. Research current models and model-specific runtimes using primary GitHub, Hugging Face, platform and announcement evidence. Evaluate speed, word error rate, download/installed size, process RAM, CPU/GPU/Neural Engine work and sustained thermal/energy costs on Devesh's iPhone 17 Pro Max.

Accepted design direction: minimalist Apple-style controls, standard readable typography, clear functional labels, meaningful symbols only, and proper light/dark modes on both platforms. Remove decorative slogans, redundant headings and subtitles. Preserve useful actions such as dictating, choosing a model, copying and sharing. The earlier editorial UI candidate is superseded.

Phonon-2 is the model Devesh saw. He approved pinned FluidAudio 0.17.5 Core ML integration and iPhone provisioning/installation using the existing developer team. Devesh subsequently selected Parakeet Realtime as the iPhone default for fast live dictation, retaining Phonon-2 for formatted text. Runtime implementations must remain replaceable. Phone performance, rather than Mac benchmarks or model size alone, determines the selected profile.

Latest iPhone correction: prioritize reliable, immediate microphone capture, model selection directly on Dictate, live transcription and recordings longer than two minutes. Retain a prepared foreground model instead of routinely unloading it after 60 seconds. Use bounded audio queues and model-specific streaming; distinguish overlapping-window recognition from true cached streaming. An idle keyboard deadline must not end active dictation. Devesh authorized inspecting Wispr Flow on the connected phone through Device Hub and on the Mac where available. Better usability and measured quality are the target; do not claim superiority without comparison.

Improve the existing Mac LocalScribe UI while preserving the working installation, application identity, local model runtime and Control–Space dictation. Devesh authorized rebuilding and replacing the Mac app, deleting the old installed bundle, and committing/pushing both projects. Restart only LocalScribe for updates; do not restart macOS. After unreadable encrypted history and dictionary entries blocked new terms, Devesh authorized replacing the Mac personal-data store. Keep model files and dictation settings; move the previous store to recoverable Trash. This reset does not apply to the iPhone.

Latest desktop direction: inspect the installed Wispr Flow desktop app with computer use and improve both appearance and useful functionality. Adapt observable interaction patterns to local processing; preserve original branding and avoid promotional text, redundant controls and unsupported feature claims. Direct model access and proper dictionary/snippet editing are current concrete improvements.

The model research and its evidence live in `docs/MODEL_RESEARCH.md`. Remaining delivery work and verification status live in `tasklist.md`.

Devesh requested an iPhone Action Button shortcut: first hold starts recording, second hold finishes local transcription and copies it to the clipboard; show useful recording/processing/result states in Dynamic Island. Use native App Intents, ActivityKit and a widget extension, with fallback if Live Activities are disabled. Follow iOS inference permissions and runtime-reported capabilities; no unsupported background Neural Engine claim.

Mac memory correction: do not enforce estimated model RAM plus a physical-RAM-scaled reserve as a load requirement. Attempt explicit quality selections, use estimates only for Auto preference, and report real allocation/load failures without silently substituting models.

Latest Action Button correction: Devesh reports the shortcut completes without a visible recording or recognized speech. Repair and test the recording-intent lifecycle rather than treating shortcut discovery/build success as functional completion. Streaming dictation needs a rolling three-sentence preview beneath the Dynamic Island and automatic advancement; respect iOS system control over expanded presentation and the unpunctuated Realtime output. Devesh will operate phone controls and verify the resulting shortcut.

Current iPhone feature direction: compare the latest reliable Wispr Flow iOS documentation/releases online, using phone inspection only for decision-changing evidence gaps. Preserve LocalScribe’s live/periodic recording preview, and add local features that need no additional model: searchable word/phrase replacements, spoken snippets, saved notes, history management and useful settings. Transforms, cloud/account/team services and new models are deferred. Use explicit deterministic replacement rules; do not imply decoder vocabulary learning.
